# Pricecalculator

## 概要
`Pricecalculator` は、コンソール上で商品名、個数、値段を入力すると合計金額を計算して表示する Java アプリケーションです。

- 入力値のバリデーション機能付き
- 不正な値の場合は再入力を促す
- 最大個数は 99、最大価格は 9999 円
- 
## 使用方法

1. コマンドラインでコンパイル:
javac com/example/Pricecalculator.java


2.実行:

java com.example.Pricecalculator

3.プロンプトに従って入力:

商品名を入力してください: ペン
個数を入力してください: 5
値段を入力してください（円）: 120

4.計算結果が表示されます:

----- 計算結果 -----
商品名: ペン
個数: 5
値段: 120円
合計金額: 600円

入力制約

商品名: 空白不可
